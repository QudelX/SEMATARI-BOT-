# 📸 Бот, который пишет текст на фотках

Короче, это Telegram-бот. Кидаешь ему фотку, пишешь текст, и он возвращает тебе эту же фотку, но с надписью. Всё. Без регистраций, без лишних кнопок, просто работает.

Написан на Python как учебный проект.

## Чо он умеет

- **Вариант 1.** Отправляешь фото сразу с подписью, и бот моментально шлёт фотку обратно с этим текстом.
- **Вариант 2.** Отправляешь фото без подписи, бот спрашивает, чо писать, ты отвечаешь текстом, и готово.
- Текст стоит по центру внизу, белый с чёрной обводкой, так что читается на любом фоне, хоть на тёмном, хоть на светлом.
- Если текст длинный, бот сам делит его на строки и подбирает размер шрифта, чтобы всё влезло.

## Что внутри (технологии)

| Что | Зачем |
|---|---|
| Python | сам язык, на нём всё написано |
| `python-telegram-bot` | чтобы бот общался с Telegram |
| `Pillow` | чтобы рисовать текст на картинке |

## Как запустить

1. Поставь [Python](https://www.python.org/downloads/). На Windows обязательно галочка **Add Python to PATH**, иначе потом будешь материться.
2. Скачай `bot.py` из этого репозитория.
3. Создай бота в Telegram: найди **@BotFather**, отправь `/newbot`, придумай имя и получишь токен.
4. Открой `bot.py` и вставь свой токен вместо заглушки:

   ```python
   TOKEN = "ТВОЙ_ТОКЕН_СЮДА"
   ```

5. Поставь библиотеки:

   ```
   py -m pip install python-telegram-bot pillow
   ```

6. Запускай:

   ```
   py bot.py
   ```

7. Заходи в Telegram, находи своего бота, жми `/start` и кидай фотку. 🔥

> Бот отвечает, только пока программа запущена и комп включён. Закрыл окно, бот помолчал.

## ⚠️ Токен не свети

Токен это как пароль от бота. Кто его знает, тот может им рулить.

- Не заливай на GitHub файл с настоящим токеном.
- Не кидай его в чаты и скриншоты.
- Если всё-таки засветил, иди к **@BotFather**, пиши `/revoke` и получай новый. Старый сразу умрёт.

## Если что-то не работает

- **`No module named 'PIL'`**: не поставил Pillow. Выполни команду из пункта 5.
- **Вместо букв квадратики**: у шрифта нет кириллицы. Положи рядом с `bot.py` любой шрифт с русскими буквами и назови его `font.ttf`.
- **Бот молчит**: проверь, что программа запущена и токен вставлен без лишних пробелов.
